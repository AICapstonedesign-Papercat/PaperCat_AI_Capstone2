## 1. 한 줄 정의

입문자를 위한 AI 논문 학습 게이미피케이션 앱

## 2. 제품 목표

논문 학습 입문자가 어려운 논문을 부담 없이 발견하고 이해하며, 보상과 기록을 통해 꾸준히 학습하도록 돕는다.

## 3. 배경

논문은 전문 용어와 복잡한 구조 때문에 입문자가 시작하기 어렵다. PaperCat은 AI 스토리텔링 설명과 단계형 학습, 게임 요소를 결합해 논문 학습을 쉽고 지속 가능한 경험으로 만든다.

목표는 논문 큐레이션·스토리텔링·채점·Q&A·방법론 시각화까지 학습 사이클 전 구간을 실데이터·실 LLM 응답으로 완성하고 실제 배포까지 가는 것이다.

**성공 기준**

1. **배포** — TestFlight 외부 테스터 배포 성공, App Store 심사 제출, 크래시 리포팅 수신
2. **실연동** — 큐레이션·스토리텔링·채점·Q&A는 실데이터·실 LLM 응답으로 전환 완료. 방법론 시각화는 아직 미착수(D-04), RAG 기반 근거 제시는 아직 미통합(D-03)
3. **시연 무장애** — 논문 3편 왕복 시연에서 429·크래시·오표시 0회
4. **품질 게이트** — RAG 통합 시 범위 내 골든셋 15문항 중 12문항 이상 근거 지지, 범위 밖 6문항 전건 거절

## 4. 문제 정의 근거

**인터뷰(경기도경제과학진흥원 GBSA)에서 나온 문제 정의**:

> 기존의 AI 교육 프로그램들은 이산적인 형태의 난이도를 가지고 있어, 교육을 받는 사람은 실제로 들어보기 전에는 그 난이도가 본인에게 적합한지 판단하기 어렵다.

핵심은 콘텐츠 부족이 아니라 학습 경험이 띄엄띄엄 끊겨 있어 학습자가 자신의 위치와 다음 단계를 가늠 못 한다는 것이다.

**행동 관찰(AEIOU)** — AI 논문에 관심 있는 비전공자의 패턴: 논문 PDF를 열어 Abstract만 읽고 닫은 뒤 유튜브 설명 영상을 검색하거나, ChatGPT에 논문을 붙여넣거나 구글 번역을 돌린다. 대상은 비전공자, 직무전환 준비생, AI 도구를 쓰지만 원리는 모르는 개발자다.

**원인 분석(5 Whys, 3개 체인)**

*체인 1 — AI 교육 수요가 왜 느는가 (거시 배경)*
AI 이해·활용력이 핵심 경쟁력이 됨 → 단순 툴 사용을 넘는 원리 이해 인재가 필요함 → AI는 발전 속도가 빨라 교과서화까지 시간차가 생김 → 최신·깊은 원리는 논문(1차 연구 결과물)에만 있음 → **근본원인: 논문을 직접 읽고 해석하는 능력이 AI의 근본을 내 것으로 만드는 유일한 길이다.**

*체인 2 — 논문 읽기를 포기하는 이유 (동기 문제)*
처음 읽으면 무슨 말인지 모름 → 전문용어·배경지식 부족 → ChatGPT로 요약은 되지만 무엇을·어디서부터 질문할지 못 찾아 학습 동기가 안 생김 → 성취감·시각화된 피드백 부재로 지속이 어려움 → **근본원인: 논문의 주 독자는 스스로 동기부여 가능한 연구자들이라 입문자의 이해·성취 경험이 애초에 고려되지 않는다.**

*체인 3 — 질문 포인트를 찾기 어려운 이유 (인지 문제)*
처음 읽으면 무슨 말인지 모름 → 전문용어·배경지식 부족 → 요약은 되지만 무엇을 물어야 할지 파악이 안 됨 → 등장하는 개념을 다 공부하기엔 학습 부담이 크고 입문자에게 직관적이지 않음 → **근본원인: 논문은 해당 분야 기본지식을 갖춘 연구자 대상으로 쓰여 초보자용 단계적 설명·학습경로가 없다.**

**HMW(How Might We)**: 전공지식 없이도 핵심을 이해하게 하려면? 학습을 꾸준히 지속할 동기부여를 어떻게 줄까? 읽은 논문이 체계적으로 관리·누적되게 하려면?

## 5. 타겟 사용자

두 페르소나는 5 Whys의 서로 다른 두 갈래(동기 문제 vs 인지 문제)를 대표하도록 설계됐다.

**잼민이 (23세, 경영학과/인문학부 대학생)** — AI 원리 이해가 필수 교양이라 생각해 스터디에 참여했지만, 기초 논문·기술 문서를 혼자 읽어보기로 결심했다. 학점·자격증·취업처럼 명확한 보상이 없으면 논문을 읽다 금방 동력을 잃고, 스스로 성장했는지 체감할 수 없어 며칠 만에 포기한다. "내가 새로운 개념을 하나씩 마스터하고 있다는 걸 눈으로 확인하고 싶어요." 필요한 것은 도감 형태의 학습 기록 — 신경망·강화학습 같은 개념을 이해할 때마다 시각적 지식이 채워지는 자발적·게임 같은 학습 동기. **핵심 결핍: 학습 동기 부재.**

**지피티 (28세, 문과 출신 서비스 기획자/마케터)** — 챗GPT 등 생성형 AI를 자주 쓰면서 기술의 근본 원리를 이해하고 싶어졌고, 유명한 논문을 직접 읽어보며 깊은 지식을 얻으려 한다. 첫 페이지부터 쏟아지는 전문 용어와 수식 때문에 머리가 아프고, AI 챗봇에 물어보려 해도 전체 그림이 안 그려져 무엇을 질문해야 할지조차 모른다. "복잡한 수학 기호는 빼고, AI가 똑똑하게 과정을 동화책 같은 스토리로 먼저 보여주고 싶어요." 필요한 것은 스토리텔링·시각화 — 논문 구조를 대중 눈높이의 시나리오·직관적 이미지로 번역해 인지 부담과 진입 장벽을 제거하는 것. **핵심 결핍: 질문 방법을 모르는 인지·구조 문제.**

| 페르소나 | 결핍 | 대응 장치 |
|---|---|---|
| 잼민이 | 동기 | 도감·XP·스트릭·배지 (게이미피케이션 축) |
| 지피티 | 인지 | 스토리텔링·시각화·Q&A 예비 질문 (접근성 축) |

## 6. 차별점 · 디자인 원칙

**포지셔닝**: RAG+LLM 요약재서술 트렌드와 듀오링고식 게이미피케이션 트렌드가 만나는 지점.

**독창성 주장 4가지** — 스토리텔링+시각화 결합, 다관점 의견, 한 줄 요약+도감 결합, 하나로 이어지는 학습 사이클. 다만 "세계 최초·유일" 주장은 하지 않으며, 깊이 있는 원리 학습은 스스로 인정한 약점으로 남겨둔다.

**경쟁 구도** — 듀오링고·Yuspeak·라이너(스콜라)·문라이트 같은 서비스와 비교했을 때, 학습 지속 동기·비전공자 스토리텔링·진입 마찰 최소화는 강점이지만 깊이 있는 원리 학습은 약점, 논문 탐색·검색 DB 범위는 부분적이라고 스스로 진단한다.

**앱에서 실제로 성립해야 할 차별점 3개(현재 0개 성립)**: RAG 기반 근거 표시·거절(F-16/F-10, D-03), 방법론 시각화(F-08, D-04), 다관점 해석(F-09, D-05). 미결 결정이 풀려야 성립한다.

## 8. 핵심 유즈케이스

**UC-01. 학습한 논문을 도감에 저장**
액터: 사용자, 외부 평가 AI. 사전조건: 가입 회원, 한 줄 요약 챌린지 화면 진입.
흐름: 요약 작성·"AI 채점받기" → 서버가 텍스트·논문 ID를 평가 API로 전송, 로딩 표시 → 채점 결과·피드백 수신, 점수·피드백 표시 → "완료하기" → 완료 상태 처리, XP·완료 수 증가·리레벨업 계산, 축하 애니메이션·'도감에 저장됨' 배지 → 도감 메뉴에서 해제된 카드가 메달과 함께 렌더링.
예외: 게스트가 시도하면 외부 서버 전송 전에 가입 유도 배너를 먼저 보여주고 과정을 진행하지 않는다. AI 서버 통신 실패 시 로딩 시간 초과 후 오류 메시지와 재시도 안내.

**UC-02. 관심 분야 기반 맞춤형 논문 추천**
액터: 사용자, 추천 서비스, 외부 논문 API(arXiv·Semantic Scholar 등). 사전조건: 온보딩에서 관심 분야 설정 완료.
흐름: 홈 진입 → 스토어에서 관심 분야 배열 로드 → 추천 서비스 호출 → 내부 DB 우선 검색 → 있으면 반환, 없으면(폴백) 외부 API를 키워드로 검색해 포맷팅·캐싱 후 합류 → 카드 형태로 렌더링, "이 논문으로 공부할래냥?" 제안 → 수락 시 논문 상세로 이동.
대안 흐름: 관심 분야가 없거나 캐시 만료 시 전체 인기·최신 논문으로 기본값 처리하거나 관심 분야 설정을 먼저 안내.

**UC-03. 논문 스토리텔링 변환 및 제공**
액터: 사용자, 스토리텔링 서비스, 외부 생성 AI. 사전조건: 논문 상세 화면 진입, 원문 데이터 확보, 스토리텔링 시스템 프롬프트 정의됨.
흐름: '스토리텔링 보기' 요청 → 내부 DB 우선 조회 → 있으면 즉시 반환 → 없으면 서론 텍스트+시스템 프롬프트를 외부 AI로 전송 → 생성된 텍스트를 DB에 저장 후 반환 → UI 렌더링.
예외: 외부 AI 생성 실패 시 에러 메시지와 "잠시 후 다시 시도해주세요" 안내.
프롬프트 원칙: 논문의 서론과 결론을 두 문단·5~7문장의 동화로, 모델명을 등장인물로 의인화해 풀어 쓰며, 동일 입력에는 동일 출력을 보장한다.

## 9. 기능 상세

표기: `state`(done/partial/missing/blocked), `priority`(P0 배포 차단 / P1 핵심가치 / P2 품질·운영 / P3 선택). gap 뒤 `[A-Hxx/Mxx/Lxx]`는 §14 감사 목록, `[D-xx]`는 §11 미결 결정을 가리킨다.

### F-01 온보딩 — P0, partial
**흐름** Splash(영상) → PlayFirst(기능 미리보기) → CatAdoption(고양이 입양) → InterestPicker(관심분야 복수 선택) → StreakCommit(스트릭 약속) → 메인 탭. 가입은 요구하지 않고 게스트로 진입시킨다("가치 우선, 가입 후행").
**예외** 스플래시 영상 onError 부재 — 실패 시 무한 멈춤 `[A-H04]`. InterestPicker 정원(3개) 도달 후에도 바운스 애니메이션이 재생돼 선택 실패를 인지 못함 `[A-M13]`.
**수용 기준** 영상 실패 상태에서도 3초 내 온보딩 진행 가능. 정원 도달 시 미선택 카드는 disabled 또는 실패 피드백.

### F-02 인증·프로필 — P0, partial
**흐름** AuthScreen(로그인/가입 단일 화면) → 가입 시 `handle_new_user` 트리거가 `profiles` 행 생성 → 로컬 store와 Supabase 동기화(프로필 upsert 큐 + progress push).
**예외** 게스트 진행이 가입 시 소실 — hydrate가 신규 빈 프로필로 덮어씀 `[A-H05]`. 가입 name/birthdate가 metadata에만 저장, 사용처 없음 `[A-M12]`. Supabase 에러 영어 원문 노출 `[A-M10]`. 생년월일 number-pad로 하이픈 입력 불가 `[A-M11]`. 약관 체크박스에 문서 연결 없음 `[A-L05]`.
**수용 기준** 게스트로 논문 1편 완료 후 가입하면 XP·도감·진행이 계정으로 승계. 에러는 한국어.

### F-03 게스트 모드 — P1, done
**동작** 학습·도감·프로필 탭과 '한 줄 요약 저장' 진입 시 잠금·배너. 게스트 변형 4장(홈·학습·도감·프로필)과 동일 동작.

### F-04 논문 카탈로그·자동 발견 — P1, partial
**흐름** ExploreScreen 카테고리 탭 선택 → 세션당 1회 `discover-papers` 호출 → Gemini가 실존 논문 최대 5편 반환 → `papers` INSERT → 목록 갱신.
**예외** 인용수 데이터 없음 — 메달·등급 근거 부재 `[D-02]`. 서비스롤 쓰기인데 인증 없음(NF-01 1순위). 환각/과장 인용수가 검증 없이 영구 삽입 `[A-H12]`. 동시 요청 중복 삽입 레이스 `[A-M18]`, citesThousands 비정상 시 'NaNk+' 저장 `[A-L08]`. 검색 안내 '제목·저자·키워드'인데 실제 매칭은 제목만 `[A-M06]`. TRENDY 하드필터로 결과 소멸 가능 `[A-L01]`.
**수용 기준** 환각 논문 0건, 동일 카테고리 반복 진입 중복 INSERT 0건, 안내 문구=실동작.

### F-05 홈·오늘의 추천 — P1, partial
**동작** 관심분야 일치 논문 우선 추천, 없으면 전체 풀 폴백(UC-02의 클라이언트 구현). 오늘의 도전·이어 학습 카드 표시.
**예외** '이어서 학습하기'가 최근 논문이 아니라 progress 삽입 순서상 첫 미완료 논문 고정 노출 `[A-M03]`.
**수용 기준** 관심분야 우선 추천·전체 폴백. 이어 학습은 updated_at 최신 논문.

### F-06 논문 개요 — P1, partial
**동작** PaperDetail 진입 시 `generate-overview` 호출, `paper_overviews` 캐시 우선 조회 후 없을 때만 생성·저장. 캐시 히트 0.5~0.8초. 이 캐시 패턴이 F-07·F-09 확장의 기준 구현이다.
**예외** paper.id/title 미검증 — 조작된 title로 공유 캐시 영구 오염 가능 `[A-H10]`. paper 미로드 시 스피너 무한 회전 `[A-M09]`.
**수용 기준** 캐시 히트 1초 내, 서버가 papers에서 title 직접 select, 로딩 상태 에러 분기.

### F-07 스토리텔링 변환 — P1, partial
**목적** 서론을 비유·이야기로 재가공해 첫 화면의 압박을 줄인다(차별점 1).
**예외** 서버 캐시 없음 — 재방문마다 재호출, temperature 0.9라 내용도 매번 달라짐 `[A-M07]`. 원문 미사용({title,year,cat}만) — 사실/비유 분리 검증 불가 `[D-03 연관]`.
**수용 기준** paper_overviews 패턴 그대로 확장, 재진입 캐시 히트, 동일 논문 동일 출력.

### F-08 방법론 시각화 — P1, blocked(D-04)
**목적** 논문 핵심 구조를 글보다 먼저 그림으로 보여준다(차별점 1의 나머지 절반). 방식은 아직 미확정이다.
**제안** layoutHint 라우팅 — 응답 스키마에 `layoutHint` 필드 1개 추가, flow·comparison 2종 네이티브 레이아웃으로 라우팅. 외부 의존성 0으로 시작.
**수용 기준** D-04 확정 후 기재. 미지의 layoutHint 값은 현행 세로 리스트로 폴백.

### F-09 다관점 토론 — P2, partial
**현행** `generate-discussion`이 단일 Gemini에 찬반 역할극 프롬프트를 분리 적용. 사용자 투표는 `discussion_votes`에 기록. "여러 AI"라는 기존 문구와는 다른 구현 `[D-05]`.
**예외** 캐싱 없음 `[A-M07]`. vote()에 언마운트 가드 없음 `[A-M08 연관]`. SELECT 정책이 넓어 임의 인증 사용자가 누가 어느 편에 투표했는지 전수 조회 가능 `[A-M19]`.
**수용 기준** 찬반 논지 실제 상충, 투표 원자 기록, 집계는 RPC/뷰로 제공하고 원본 행 비노출.

### F-10 Q&A 챗봇 — P1, partial
**목적** 무엇을 질문할지 모르는 입문자를 위한 예비 질문 박스와 즉답.
**현행** 논문 메타데이터 컨텍스트로 Gemini 응답. 원문 미사용 — 근거 첨부·인용·범위밖 거절이 없어 차별점이 성립하지 않는다 `[D-03]`.
**예외** paper.title이 시스템 프롬프트에 그대로 삽입 — 페르소나 우회 가능 `[A-M16]`. send()에 언마운트 가드 없음 `[A-M08]`.
**수용 기준(D-03 통합 후)** 골든셋 게이트 — 범위내 15문항 중 12 이상 근거지지, 범위밖 6문항 전건 거절.

### F-11 한 줄 요약 챌린지·AI 채점 — P0, partial
**목적** 수동 소비를 능동 정리로 바꾸는 학습 사이클의 필수 관문.
**흐름** 요약 작성 → 'AI 채점받기' → `grade-summary` → 점수·피드백 표시 → '완료하기' → `record_challenge_attempt` RPC(원자적 기록) → XP·완료 수 갱신 → 도감 잠금 해제. 게스트는 채점 요청 전에 가입 유도 배너.
**예외** 채점 실패(Gemini 503)가 0점 '통과'로 위장, XP까지 지급 — 시연 킬러 1순위 `[A-H01]`. summary가 프롬프트에 무방비 삽입 — 인젝션으로 점수 조작 가능 `[A-H11]`. 채점 스케일 미합의 `[D-01]`. 골든셋 humanScore가 인성 초안뿐 — 성민 실채점 전 게이트 숫자 인용 금지.
**수용 기준** 채점 실패는 오류+재시도(통과 금지). 프롬프트에 데이터/지시 분리 앵커링. 통과 시 원자 기록 1회.

### F-12 스테이지맵 — P0, partial
**목적** 학습을 단계(개요→스토리텔링→활동→요약→완료)로 표시하고 순서를 강제한다.
**예외** progress가 스칼라 1개 — 뒷 단계 먼저 열면 전부 완료로 표시 `[A-H03]`. 남은 시간이 스테이지당 3분 고정 더미 `[A-L03]`.
**수용 기준** 요약 미통과 시 다음 단계 진입 차단. 표시=실이력.

### F-13 학습 완료·보상 — P2, partial
**동작** LearningComplete에서 XP 부여·레벨 연출(XPBurst)·축하(골골송). 완료 논문 수 증가.
**예외** hearts 소비처 없음 — 게이미피케이션 3축(하트·번개·XP) 중 하트가 죽어 있음. 골골송 decodeAudioData 실패 시 rejected Promise가 캐시돼 세션 내내 소리 안 남 `[A-L06]`.
**수용 기준** 보상 중복 부여 0회, 오디오 실패 시 다음 호출에서 재시도.

### F-14 도감·메달 수집 — P1, partial
**동작** 완료 논문은 잠금 해제 카드, 미완료는 실루엣. 분야 필터. 배지 에셋 20종(골드·실버 각 10).
**예외** 메달 근거 데이터(인용수) 없음 `[D-02]`. 분야별 학습 비율에서 '생성AI' 카테고리 통째 누락 `[A-M02]`.
**수용 기준** 완료=해제 카드/미완료=실루엣, 분야 필터 4종 전부 집계, 비율 합 100%.

### F-15 학습 통계·스트릭·프로필 — P0, partial
**동작** 주간 차트·최근 활동(daily_activity·paper_progress 실데이터). 스트릭은 `touch_daily_streak` RPC.
**예외** 탭 복귀 시 재조회 없음 — 시연 킬러 `[A-H02]`. weeklyMinutes 리셋 로직 전무, Home과 Study의 '이번 주'가 다른 숫자 `[A-H08]`. touch_daily_streak UTC 기준 — KST 자정 근처 오판 `[A-H09]` + 행 잠금 없어 동시 호출 이중 증가 `[A-L11]`. 30초 미만 세션 매번 절삭 유실 `[A-M14]`, 백그라운드 체류가 학습시간으로 집계 `[A-M15]`. 선형 그래프 주 초반 x축 어긋남 `[A-M04]`, 알림·다크모드 스위치 순수 더미 `[A-M05]`.
**수용 기준** 완료 직후 focus 재조회 반영. 주간=daily_activity 월~일 합산 단일 정의. 스트릭 KST 일 단위.
